次を確認して、Discord にそのまま貼れる日本語の Markdown を **1800 文字以内** で出力する。前置き・後書き・質問は書かない。**出力の1行目は必ず `**💴` で始める。**
数字は見つかった事実だけを書き、確認できないものは「未確認」と書く（推測で埋めない）。
