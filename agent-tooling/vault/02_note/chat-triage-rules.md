# チャットの仕分けルール（`/slack`・`/discord` が使う判断基準）

`/slack`・`/discord` が未読を仕分けるときの基準。**本人が提案を直したら、ここに追記する。** 手順はスキル側。

> [!note] これはひな形
> 元の持ち主のワークスペース・サーバーごとの決まりと修正の記録は、個人情報なので抜いてある。

## 方針

- 提案 → 本人が Yes/No で承認 → 実行。返信は全文を見せてから送る。
- 自分宛て（DM・メンション）だけを見る。

## 共通

| 対象 | 既定 | メモ |
| --- | --- | --- |
| 自分への質問・依頼・日程調整 | **タスク**（返信の下書きを notes に入れる） | 返信はその場で送らず、本人が決めてから |
| お礼・了解・報告への区切り | リアクション（`+1` / `pray` / `ok_hand` など） | 文章で返すほどでないもの |
| 雑談・自分の対応が要らない連絡 | 無視 | |
| お金・日程・締切が絡むもの | 1件ずつ聞く | |
