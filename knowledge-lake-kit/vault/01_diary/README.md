# 日記

日々の記録。**1日1ファイル**、`YYYY/YYYYMMDD.md`（例: `2026/20260415.md`）。ひな形は [`../79_template/daily-note-template.md`](../79_template/daily-note-template.md)。

## 集めるもの

- その日にあったこと、感じたこと、会った人、食べたもの、体調
- 長く書かなくてよい。3行でも続ける方が価値がある

## 集めないもの

- 後から判断に使う事実（制度・手続き・住所・買った物の型番など）は、日記から該当フォルダのノートへ**移す**。
  日記は「その日の自分」、他のフォルダは「後で引く事実」。AI に「今週の日記から残すべき事実を拾って各ノートへ反映して」と頼むと育つ。

## 運用

- スマホで書くなら、Obsidian のデイリーノート機能（コアプラグイン）でフォルダ・ファイル名形式・テンプレートを上の形式に合わせる。
- スマホと PC の両方から書くなら、同じ日付のファイルを同時に編集しない。競合したらスマホ側を優先する。
- 慣れてきたら日記だけ別リポジトリ（Git サブモジュール）にする選択肢がある → [`../02_note/knowledge-lake-method/05_git-and-phone.md`](../02_note/knowledge-lake-method/05_git-and-phone.md)

## 取り扱い

通院・服薬や、他人のことが自然に入る。保管庫の外へ出さない。公開する文章に引用するときは、他人の情報を落とす。
