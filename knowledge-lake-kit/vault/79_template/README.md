# テンプレート

再利用するためのひな形を置く場所です。新規ノートを素早く作るための最低限の型。

## 目次

- [`daily-note-template.md`](./daily-note-template.md): 日記
- [`note-template.md`](./note-template.md): 一般のノート
- [`decision-template.md`](./decision-template.md): 意思決定ログ（`00_self/decisions/`）
- [`person-template.md`](./person-template.md): 人物（`08_people/`）

## 運用

- テンプレートは、空欄を埋めるだけで使える状態に保つ。具体的すぎる内容は入れない。
- Obsidian の「テンプレート」コアプラグインで、テンプレートフォルダをここに設定する。
