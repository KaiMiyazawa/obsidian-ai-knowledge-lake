# サービスとアカウントの対応表

**どのサービスに、どのアカウントで入っていて、AI からどの手段で届くか。** サービスを触る前に AI が読む。
パスワードなど秘密の値は書かない（パスワードマネージャーの項目名だけ書く）。

| サービス | アカウント | 用途 | AI から届く手段 |
| --- | --- | --- | --- |
| Gmail | （例: 個人 xxx@gmail.com） | 個人の連絡 | （例: MCP / なし） |
| Google Calendar | | 予定（全部ここに集約） | |
| Google Tasks | | 実行タスク | |
| GitHub | | 保管庫のリポジトリ（private） | `gh` CLI |

## 複数アカウントがあるとき

- 個人・仕事・学校でアカウントが分かれるなら、**AI がどのアカウントに繋がっているか**をここに書く。
  「MCP がある」ではなく「このアカウントに繋がっているか」で AI は判断する。
- Codex と Claude で繋いでいるアカウントが違うなら、それも書く。
