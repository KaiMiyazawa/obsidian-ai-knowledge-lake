# 汎用メモ

進路、制度、手続き、調べもの、使っているサービス、AI の運用など、**「あとで参照して判断に使う」**メモを置く場所です。
どのフォルダにも入らないが残す価値のあるものは、まずここ。

## 集めるもの

- 調べたこと（制度・手続き・比較検討）と、その結論
- 使っているサービス・アカウントの対応表 → [`services-accounts.md`](./services-accounts.md)
- AI に繋いでいる MCP と、入れなかったもの → [`mcp-inventory.md`](./mcp-inventory.md)
- 保管庫そのものの運用方法 → [`knowledge-lake-method/`](./knowledge-lake-method/)
- 繰り返す作業の手順（ブラウザ操作の手順など）

## 集めないもの

- 実行タスク（「〜する」）→ タスク管理ツールへ
- 一時的な作業メモ → `../tmp/`

## 使い方

- 断片的なメモをまず置く。重要なものは、まとまったノートへ育てる。
- テーマが大きくなったら、専用の番号付きフォルダへ独立させる（例: 投資のノートが増えたら `09_investment/`）。
- ノートを足したら下の目次に1行足す。

## 目次

- [`knowledge-lake-method/`](./knowledge-lake-method/): この保管庫の作り方・運用方法の原本
