# MCP の一覧と、入れない判断

**この保管庫で AI に繋いでいる MCP と、検討して見送ったもの。** 新しい MCP を検討する前にここを見る。

> [!important] 判断の基準
> **AI はこの PC のファイルシステムと CLI（`git`・`gh` など）を直接持っている。**
> したがって MCP に価値があるのは、**この PC から届かないデータ**に手が伸びるときだけ。
> 手元にあるものを MCP 経由にすると、遅くなるうえに壊れる箇所が増える。

## 接続済み

| MCP | アカウント | 何ができるか | 書き込みの承認 |
| --- | --- | --- | --- |
| （例: Google Calendar） | （例: 個人） | 予定の検索・作成・変更 | 作成・変更は毎回承認 |

## 検討して、入れないと決めたもの

**理由を必ず書く。** 次に同じ検討をしたとき、AI が同じ調査をやり直さずに済む。

| MCP | 判断 | 理由 |
| --- | --- | --- |
| Obsidian MCP | 入れない | 保管庫はローカルにあり、AI がファイルとして直接読み書きできる。プラグイン経由にする理由がない |
| GitHub MCP | 入れない | `gh` CLI で足りる |
| （非公式の金融・パスワード系 MCP） | 入れない | 認証情報を預ける相手として信頼できない。公式でないものに口座やパスワード全体へのアクセスを渡さない |

## 設定の場所

- Codex: `~/.codex/config.toml`（全体）、`.codex/config.toml`（この保管庫だけ）
- Claude Code: `claude mcp add`、`.mcp.json`（この保管庫だけ）、`.claude/settings.json`（許可リスト）
