# 意思決定ログ

**なぜそう決めたか**を、1決定1ファイルで残す場所。

結論だけなら [`../timeline.md`](../timeline.md) にある。ここに残すのは、
結論に至った理由、比較した選択肢、そして**その判断がどういう前提の上に立っていたか**。

前提が変わったときに判断を見直せること、そして将来の似た判断で同じ思考を再現できることが目的。
AI にとっては「この人ならどう考えるか」を学ぶ一番の材料になる。

## 書き方

ファイル名は `YYYY-MM_slug.md`。月まで特定できないときは `YYYY_slug.md`。
ひな形は [`../../79_template/decision-template.md`](../../79_template/decision-template.md)。

| 項目 | 何を書くか |
| --- | --- |
| **背景** | そのとき何が起きていて、何に困っていたか |
| **選択肢** | 実際に検討した案。採らなかった案も書く |
| **決め手** | 最終的に何が決定的だったか。1〜2行で言い切る |
| **前提が崩れる条件** | この判断が成立しなくなるのはどういうときか |
| **その後** | 実際どうなったか。時間が経ってから追記する |

## 原則

- **後から美化しない。** 打算や消去法で決めたなら、そう書く
- 感情も理由のうち。合理的でない決め手も、そのまま書く
- 事実と解釈を分ける。「〜だった」と「〜だと思う」を混ぜない
- 分からないことは「未確認」と書く
- 過去の決断も、思い出せる範囲で遡って書いてよい（進学・就職・引っ越しなど）
