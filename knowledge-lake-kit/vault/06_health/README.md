# 健康

体の記録。通院・検査・薬・体質・運動。

## 集めるもの

- かかりつけの病院・クリニック（科目・場所・初診日・診察券番号の有無）→ `clinics.md`
- 健康診断・検査の結果（数値は年ごとの表にすると AI が推移を読める）
- 飲んでいる薬・アレルギー・既往歴
- 運動・睡眠の習慣と、試して効いたもの・効かなかったもの

## 集めないもの

- 検査結果の PDF 原本を大量に置かない。必要な数値をノートに書き起こし、原本は `.gitignore` で除外するか保管庫の外へ

## 取り扱い

> [!warning] 機微情報
> 保管庫の外へ出さない。公開する文章（`89_profile/`・`99_public/`）から、このフォルダへリンクを張らない。
> AI に読ませるのは、受診・手続き・体調の相談など、その情報が必要なときだけ。
