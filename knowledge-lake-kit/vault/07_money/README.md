# お金（個人）

**個人のお金についての判断の文脈を置く。**

> [!important] 支出の台帳は作らない
> 日々の支出は書き写さない。原本は家計簿アプリ・銀行・カード明細に置いたまま。
> **二重管理は必ずずれるし、ずれた瞬間にどちらが正しいか分からなくなる。**
> 例外は「どのサービスも横断して見せてくれない数字」（例: 複数の収入源の年間合計＝扶養や税の壁の管理）だけ。

## 集めるもの

- 収入源の一覧と、税・社会保険・扶養への効き方 → `income-and-tax.md`
- 奨学金・ローン・保険の契約の要点と、期限
- 大きな買い物・投資の判断（なぜ買ったか・なぜ見送ったか）
- **数字はどこにあるか**の表（どのアプリ・どのスプレッドシートが原本で、AI から届くか）

## 集めないもの

- 口座番号の全桁・暗証番号・ログイン情報（パスワードマネージャーへ）
- 日々の支出明細

## 取り扱い

保管庫の外へ出さない。口座の一覧を作るなら、銀行名・支店・用途までにして、番号は下4桁まで。
