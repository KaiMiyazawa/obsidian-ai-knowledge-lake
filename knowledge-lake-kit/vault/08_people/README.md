# 人物

家族・友人・仕事相手など、**繰り返し登場する人**についてのノート。1人1ノート（`firstname.md` や関係名 `imouto.md` など）。

## 集めるもの

- その人との関係、知り合った経緯、呼び方（あだ名は [`../00_self/glossary.md`](../00_self/glossary.md) にも1行）
- 誕生日、好きなもの・苦手なもの（贈り物や店選びで AI が使える）
- 一緒に決めたこと、貸し借り、約束

## 集めないもの

- 本人の同意なく集めた詳細な個人情報、噂、評価だけのメモ

## 取り扱い

> [!warning] 他人の情報です
> 保管庫の外へ出さない。増やすときも最小限に留める。
> 公開する文章からリンクを張らない（ファイル名だけで誰か分かる）。
> AI に頼むときも「この人の情報を外部サービスへ送る」操作は確認してから。
