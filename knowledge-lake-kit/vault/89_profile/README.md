## 原則

- **事実は持たない。見せ方だけを持つ派生。** 事実の原本は [`../00_self/timeline.md`](../00_self/timeline.md)（経歴）など `00_self/`。
  ここの文章を直す前に、原本が最新か確かめる。原本にない事実をここで足さない。
- 外に出す前提なので、`06_health/`・`08_people/`・`00_self/decisions/` の内容を写すときは立ち止まる。
