# Obsidian Vault

この保管庫は、私の人生、環境、仕事、学習、記録を長期的に蓄積するためのドキュメント集です。
AI との共同作業では、毎回の前提説明を減らせるように、ここを共通コンテキストの入口として使います。

## 使い方

- まずこの `README.md` と [`AGENTS.md`](./AGENTS.md) を読む。
- 次に [`00_self/`](./00_self/README.md) を読む。私が誰で、今どのフェーズにいるかはここに集約してある。
  特に [`00_self/now.md`](./00_self/now.md) は時点依存なので、更新日を必ず確認する。
- 必要に応じて、該当する領域の README やノートを辿る。
- 一時的なメモより、あとで参照する価値がある情報を優先する。

## 構成

各番号付きフォルダは用途別の並列名前空間（番号は上下関係ではない）。

- [`00_self/`](./00_self/README.md) 自分についての一次情報（**最初に読む**）
- [`01_diary/`](./01_diary/README.md) 日々の記録
- [`02_note/`](./02_note/README.md) 汎用メモ・調べもの・判断の記録
- [`03_hobby/`](./03_hobby/README.md) 趣味
- [`04_misc/`](./04_misc/README.md) その他
- [`05_home/`](./05_home/README.md) 住まい・所有物・設備
- [`06_health/`](./06_health/README.md) 健康（**機微情報**）
- [`07_money/`](./07_money/README.md) 個人のお金（判断の文脈。**台帳は作らない**）
- [`08_people/`](./08_people/README.md) 人物（**機微情報**）
- [`10_work/`](./10_work/README.md) 仕事
- [`30_study/`](./30_study/README.md) 学業・研究・資格
- [`79_template/`](./79_template/README.md) 再利用するテンプレート
- [`89_profile/`](./89_profile/README.md) 対外プロフィール（外部に説明するときの自分）
- [`99_public/`](./99_public/README.md) 公開用の文章
- `tmp/` 一時ファイル（Git 管理外）
- `tools/` 保管庫の運用に使う小さなスクリプト

ルートの `.base` ファイルは Obsidian Bases のビュー（`HOME.base`: 最近更新・領域別、`decisions.base`: 意思決定の時系列、`hygiene.base`: frontmatter の欠落チェック）。

## 機微情報の扱い

保管庫には、公開してよい情報と、外に出したら困る情報が同居しています。
統一の分類表は作らず、**それぞれのフォルダの README に「取り扱い」として書く**方針です。作業前に、そのフォルダの README を確認してください。

特に注意が要るのは `06_health/`・`08_people/`・`00_self/identity-private.md`・`07_money/`。
逆に `89_profile/` と `99_public/` は外に出す前提です。この2つとそれ以外の間で内容をコピーするときは、必ず一度立ち止まってください。

## 記録方針

- 1つの事実は、必要な場所にだけ置く。重複させず、原本と相互参照を決める。
- 画像や添付は、参照元の近くに置く。
- ファイル名は英語、本文は日本語を基本にする。
- 将来の AI が読んだときに、単独で意味が通る粒度を意識する。
- 整理は階層を増やす前に、情報の薄いノートの統合と README への入口集約を検討する。

## この保管庫で育てたいもの

- 私の生活史と判断の履歴
- 住居、所有物、作業環境の実用情報
- 学習、仕事、制作の経緯
- AI が継続的に文脈を引き継げる知識ベース
