# 住まい・所有物・設備

住まい・家電・PC・スマホ・車など、**生活の物理的な環境**の実用情報。

## 集めるもの

- 住まい（契約・更新日・管理会社・設備の癖）→ `residences.md`
- 家電・家具（型番・購入日・保証・取扱説明書のリンク）→ `appliances.md`
- PC・スマホ・周辺機器（スペック・設定・トラブルの直し方）→ `digital-devices.md`
- ネット回線・電気・ガス・水道の契約

## 集めないもの

- 支出の明細 → 家計簿アプリのまま（`../07_money/` の方針）
