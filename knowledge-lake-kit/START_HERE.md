# まずこれを読む — ナレッジレイク スターターキット

Obsidian の保管庫を「AI と共有する長期記憶」として育てるための一式です。
作者が実際に1年近く運用して、うまく回っている部分だけを抜き出し、個人の中身を消して汎用化しました。

このファイルだけ上から順にやれば終わります。

| 手順 | やること | 時間の目安 |
| --- | --- | --- |
| [手順1](#手順1-アカウントとアプリを用意する) | アカウントとアプリを用意する | 20〜30分 |
| [手順2](#手順2-保管庫を作る) | 保管庫を作る（Codex がインタビューしながら構築） | 30〜60分 |

---

## これは何か

- **AI（Codex / Claude Code）が毎回あなたのことを説明し直さなくても、保管庫を読めば文脈が分かる**状態を作る仕組み。
- 中身は「フォルダ構成」「AI への指示書（`AGENTS.md`）」「各フォルダに何を書くかの README」「テンプレート」「AI の権限と安全装置の設定例」「運用のコツ」。
- 空の器です。中身（あなた自身の情報）は、Codex があなたにインタビューしながら埋めます。

## 手順1. アカウントとアプリを用意する

**全部あなた自身のアカウントで作ります。**

| # | 何を | どこで | 必須か | 用途 |
| --- | --- | --- | --- | --- |
| 1 | **Obsidian** をインストール | <https://obsidian.md/download> | 必須 | 保管庫を人間が読み書きするアプリ（無料、アカウント不要） |
| 2 | **ChatGPT アカウント** と **Codex** | <https://chatgpt.com> でアカウント作成 → Codex アプリ / Codex CLI を入れてログイン | 必須 | 保管庫を読み書きする AI。Claude Code を使うなら Claude のアカウントでもよい |
| 3 | **GitHub アカウント** | <https://github.com/signup> | 強く推奨 | 保管庫の履歴とバックアップ（**private リポジトリ**で使う）。スマホの AI から保管庫を触れるようにもなる |
| 4 | **Git** | Mac はターミナルで `git --version`（無ければ案内に従ってインストール）。Windows は <https://git-scm.com> | 強く推奨 | 上と同じ |
| 6 | Google アカウント（カレンダー・Tasks・Gmail） | 既にあればそれ | 任意・後でよい | AI に予定やタスクを触らせるとき |

## 手順2. 保管庫を作る

1. 保管庫にしたい空のフォルダを作る（例: `~/Obsidian`）。
2. このリポジトリをクローンし（`git clone https://github.com/KaiMiyazawa/obsidian-ai-knowledge-lake.git`）、中の `knowledge-lake-kit/` フォルダをそのフォルダの中へコピーする。
3. そのフォルダで Codex を起動し、次の一文を貼る。

```text
knowledge-lake-kit/SETUP_FOR_AI.md を読んで、その手順どおりにこの保管庫を初期構築して。
```

あとは Codex が質問してくるので答えるだけです。フォルダ構成の相談 → ひな形のコピー → Codex の設定 → あなたについてのインタビュー → Git の開始、の順に進みます。
Claude Code を使う場合も同じ一文で動きます（`AGENTS.md` は両方が読みます）。

終わったら Obsidian を開き、「保管庫としてフォルダを開く」でそのフォルダを選びます。

### その後

- 普段は保管庫を開いた状態の Codex に「〜を調べてノートにまとめて」「今日決まったことを now.md に反映して」と頼むだけ。
- 最初の1ヶ月の育て方は `guide/06_growing.md`（構築後は `02_note/knowledge-lake-method/06_growing.md`）。
