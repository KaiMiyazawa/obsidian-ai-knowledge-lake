# 手段の選び方 — ファイル・CLI・MCP・ブラウザ

## 順番

1. **ローカルのファイルと CLI。** 保管庫はローカルにあるので、AI は直接読み書きできる。GitHub は `gh` CLI で足りる。
2. **MCP / API。** PC の外にあるデータ（メール・予定・ドライブ・タスク・会計）に手を伸ばすとき。テキストで返るので速く、文脈の消費も小さい。
3. **ブラウザ操作。** API に無い操作（設定画面、MCP のないサービス）。Claude Code は Chrome 拡張（Claude in Chrome）で、**普段ログインしているブラウザのセッションをそのまま**操作できる。Codex にもブラウザ・画面操作の機能がある。
4. **デスクトップアプリの画面操作（computer use）。** ブラウザでも届かないネイティブアプリ。人の手作業に落とす前の最後の一手。
5. **人が決める。** 判断が要るものは自動化しない。

> [!important] 両方で届くなら MCP を選ぶ
> ブラウザ操作は画面を読むので、スクリーンショット数枚で MCP 数十回分の文脈を使う。
> 「ブラウザでもできる」はブラウザを使う理由にならない。

> [!note] 自動化が割に合うとき
> 3クリックで終わる設定変更を自動化しても割に合わない。価値が出るのは、**まとめて片付けるとき**と、**手順を残して再現したいとき。**

## 最初に入れるとよい MCP（優先順）

| MCP | 何が便利になるか |
| --- | --- |
| カレンダー | 「来週空いてる？」「この予定を入れて」。予定を1つのカレンダーに集約しておくと効果が大きい |
| タスク（Google Tasks など） | [`02_tasks.md`](./02_tasks.md) の運用ができる |
| メール | 受信の仕分け・返信の下書き・申込メールからの予定登録 |
| ドライブ | PDF・スプレッドシートを読ませる |

Codex なら ChatGPT のアプリ連携（コネクタ）や `codex mcp add`、Claude Code なら claude.ai のコネクタや `claude mcp add` で足す。

## 入れなくていいもの

- **Obsidian 用の MCP**: 保管庫はローカルにあるので直接読める。
- **GitHub MCP**: `gh` CLI で足りる。
- **非公式で、金融口座やパスワード全体の認証情報を預ける MCP**: スター数・保守状況・公式かどうかを確認し、信頼できなければ入れない。

入れた / 入れなかった判断は、理由付きで `02_note/mcp-inventory.md` に残す。

## ブラウザ操作で書き込むときに AI に守らせること

- どのアカウントで作業するかを明示する
- 1件ずつ、変更前の画面を確認してから進める
- 削除や一括処理はしない
- 確認ダイアログが出たら、内容を報告して指示を待つ
- エラーは2回までで止めて報告する
- **手順は使い捨てにせず、関係するノートに残す**（次回はそれを読んで再現できる）

## 複数の AI を使い分ける

Codex と Claude Code の両方を使うなら、それぞれ繋がっているアカウントが違うことがある（例: 片方は仕事用ドライブ、片方は個人用）。
自分の側にないデータが要るときは、もう片方の AI を CLI で1回呼んで取ってきてもらえる（`codex exec "…"` / `claude -p "…"`）。
どの AI がどのアカウントに繋がっているかは `02_note/services-accounts.md` に書いておく。

## 自作スキル

同じ手順を何度も頼むようになったら、スキル（手順書）にする。Claude Code は `.claude/skills/<名前>/SKILL.md`、Codex もスキル機能がある。
例: 「メールを読んで、1通ずつ『アーカイブ / 返信下書き / タスク化 / 予定登録』を表で提案し、一括承認後に実行する」スキル。
判断基準はスキルに書かず、保管庫のノート（例: `02_note/mail-triage-rules.md`）に書いてスキルから参照させると、基準を直すときにスキルを触らずに済む。

Obsidian の書式を AI に正しく書かせるには、[kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)（MIT）の `obsidian-markdown`・`obsidian-bases` を入れると便利（ただしリンクは相対パスの Markdown リンクを優先する、と `AGENTS.md` に書く）。
