# 最初の1ヶ月の育て方

## 1週目: 自分を書く

- `00_self/` を AI のインタビューで埋める（初期構築で済んでいるはず）。
- 特に `values-principles.md` の「AI への含意」。AI の返答で「こうじゃない」と感じたら、その都度1行足す。**これが一番効く。**

## 2週目: 普段の頼みごとを保管庫経由にする

調べものや相談を、保管庫を開いた状態の AI に頼み、結果をノートに残させる。

- 「◯◯の手続きを調べて、02_note にまとめて」
- 「今の家の契約内容をこのPDFから読んで、05_home/residences.md にして」
- 「◯◯さんの誕生日と好きなものを 08_people に足して」
- 「この会話で決まったことを now.md に反映して」

**会話の最後に「今日決まったこと・分かったことで、残すべきものを保管庫に反映して」と頼む癖をつける。** これだけで保管庫が育つ。

## 3週目: 過去を入れる

- `timeline.md` を遡って埋める（卒業・就職・引っ越し・資格）。
- 大きな決断を `decisions/` に1〜3件書く。思い出しながら AI と話すと書きやすい。
- 既存のメモ（スマホのメモアプリ、Google ドキュメント）を AI に読ませて振り分けさせる。

## 4週目: 外部と繋ぐ

- カレンダー・タスク・メールの MCP を繋ぐ（[`04_tools-and-mcp.md`](./04_tools-and-mcp.md)）。
- タスク運用を始める（[`02_tasks.md`](./02_tasks.md)）。
- 「毎回同じことを AI に言っている」と気づいたら `AGENTS.md` に1項目足す。

## よくある失敗

| 失敗 | 対策 |
| --- | --- |
| `now.md` が古くなり、AI が昔の前提で話す | 状況が変わったら「now.md 更新して」と一言。更新日を書く |
| 同じことを2か所に書いてずれる | 原本を決めてリンクで参照する |
| 日付付きの作業ログが積み上がって読みにくい | 「今の正解」は上書き、「なぜ」だけ残す |
| AI が推測で事実を書いた | 「未確認」と書くルールを `AGENTS.md` に。見つけたら直す |
| 分類に悩んで手が止まる | 迷ったら `02_note/` か `04_misc/`。3つ溜まったらフォルダを作る |
| ノートに `- [ ]` が溜まる | タスク管理ツールへ移し、ノートには判断だけ残す |
| 公開ブログに個人的なことが混ざる | 公開フォルダを分け、フックでも止める |
| Obsidian が重くなる | 大量データは `.data/` へ、コードは保管庫の外へ |

## 育ってきたら足すもの

- `00_self/personality.md`（性格診断の結果など、恒常的な性質）
- `00_self/skills.md`・`projects.md`（技術スキル・制作物の索引）
- 自作スキル（繰り返す手順を AI 用の手順書に）
- 公開ブログ（`99_public/`）と履歴書（`89_profile/`）を、`00_self/` から AI に起こさせる
